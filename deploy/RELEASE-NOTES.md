# 0.4.17 新开游玩不再复用已放弃的Session

**适配酒馆版本**：DSH Tavern **2.7.0 / main `a390af17`**（完整提交 `a390af170cfe5ed3e9213a2801cbcce321e2008b`，runtime sequence 617）。

其他未适配酒馆版本可能运行报错；安装接入检查通过不代表运行期功能兼容，请使用标注的酒馆版本或自行适配插件。

## 本版修复

失败开局的待完成记录保存在浏览器中。旧版放弃开局、删除对话后仍可能残留该记录，按相同人物卡/选项再次开始时复用旧Session，继而在选择酒馆预设时遇到“has already started; its agent preset is fixed”，还没进入本次开场写入。

0.4.17按侧栏两种明确状态处理：

- **新开游玩**：无条件清除旧游玩待开局记录，随后创建全新Session；包括旧版已经取消但未清理的残留。
- **继续开局**：保留当前这次记录和Session，不把继续误当新建。
- **确认放弃开局**：清除该人物卡待开局记录；未确认或忙碌时不清。
- **删除对话成功**：清除对应Session待开局记录；删除失败不清、不掩盖错误。

清理同时覆盖浏览器内存和localStorage，卡片工作台与其他设置保留。不自动删除服务器会话或存档，不改上游预设固定机制，不发起额外开场。source/bundle/runtime均进入正式受管接缝，安装与卸载沿用现场注释区块。
