# 0.4.21 stable：取消输入回退、旧轮清理与分叉冷开修复

## 目标版本

DSH Tavern **stable 2.7.0**，目标提交 `9603eca4f854b55980b632a691a0d8aec900a49a`，宿主 **DSH 0.1.5-rc.2代，peer <0.2.0**。既有生产接缝定向验证使用固定stable `47a19ee`作者树；本版三项修复已在目标stable测试实例交付，不将此表述为全部页面或跨平台安装验收。

其他未适配版本可能运行报错，请使用标注版本或自行适配。本包不是main3.0/DSH0.2兼容版；运行包名仍相同，不可与另一源码线共装。

## 本版修复

- **取消输入后可回退**：历史队列输入若已被真实取消且没有替换输入，不再误认为独立待处理输入而挡住纯尾回退；替换后仍待处理的独立输入继续保留。
- **旧轮次运行残留**：缺完整前像的旧轮恢复路径，按已有轮次裁掉目标尾的runtimeInputs，清掉目标尾的preparedWorldBook；已实际处理项不再报“缺历史值”，真正未知的历史值仍明确提示。完整新轮前像恢复逻辑不变。
- **分叉档冷开**：物理回退进入分叉继承的历史前缀时，同事务缩短SQLite继承计数，并同步内存Session及活动句柄，避免重启后因继承数超过事件总数无法加载。保留新档身份和父来源，不补造历史、不回读父档。
- **最小实现**：不新增回退资格门、校验框架或拒绝条件；保留原纯尾、身份、SQL事务/CAS与旧写隔离。

## 验证与边界

本版唯一全量：**1130 tests / 1129 pass / 1 fail**，实际叶 **1118 / 1117 / 1**，0跳过/取消，54.6秒。唯一失败是旧活动句柄测试的整对象期待未包含新增继承计数；更新夹具明确覆盖继承前缀回拨后，仅该失败断言精确复验 **1/1通过**，未修改产品实现、未重跑全量。开发期三项受影响精确断言分别通过。目标测试实例的指定受影响档仅经明确维护授权修正继承计数，并以真实Session只读冷开成功；**发行包不自动修复已经存在的历史损坏计数**。

发布不自动部署实例或改写真实数据。SQLite仍是运行数据权威，原件保留只读；不承诺跨多个SQL库原子提交。独立card-editor及其它未完成项不自动纳入本版已修范围；真实页面与连续玩法由使用者验收。
