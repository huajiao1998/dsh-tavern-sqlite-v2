# 0.4.3 标准插件装配与上游 a2008bf 适配

## 适配酒馆版本

本次更新适配上游 [DSH Tavern `a2008bf`](https://github.com/flizzywine/dsh-tavern/commit/a2008bf932031616fd80ec265cbdba5d0b559312)（Tavern 2.5.0，完整提交 `a2008bf932031616fd80ec265cbdba5d0b559312`；runtime `68dff3ddaa012bdb155424f90a8d6eb779881bde` / sequence582）。**目标酒馆适配版本以本 Release 更新说明为准，请下载前核对。**

**其他未适配的酒馆版本使用过程中可能出现运行错误。** 安装接入检查通过不代表运行期功能兼容；请更新到本 Release 标注的适配酒馆版本，或自行适配本插件后使用。酒馆升级覆盖插件区块后，请停止对应酒馆并运行一次安装维护以重接。

## 更新内容

- 标准插件目录：程序单份安装到 `data/plugins/dsh-tavern-sqlite-v2/`，一次安装保存必要区块和启动装配，以后正常启动不需要再次安装。
- 普通通信统一为 `tavern.handle` / `tavernUi.callHost`，七项存档动作继续使用同一保存服务。
- 兼容上游 `.tavern-entry.mjs` 保护入口，保留旧入口及外部占用拒绝，支持正常换代、卸载与残留维护。
- 补齐新 `editTurn` 的服务端 `MESSAGE_EDITED` 编辑事件，保留保存检查与作者通知，避免重复派发。
- 合入 PR #10 的读取与缓存优化，按实际写集失效，减少重复解析，并修正缓存记账、外部写失效和零预算禁用边界；具体收益以实际环境为准。
- 保留 SQLite 数据存储、同事务变量归档、revision CAS、读写缓存优化、物理纯尾回退和服务端 MVU；原档仍只读，需用户手动分叉到新 ID 后继续。

发布前由主执行一次全量；失败修正后仅复验失败项，未再次全量。验证覆盖相应接口与隔离调用链；完整宿主启动、真实页面及玩法需在实际环境验收。未自动迁移、清理或删除用户存档。
